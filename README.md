# Order-to-Delivery-Process-Optimization – Business Analysis Project

Overview

This project analyzes and optimizes the Order-to-Delivery workflow for an e-commerce business.
It includes documentation of AS-IS and TO-BE processes, a Business Requirements Document (BRD), and Jira-style user stories.

Objectives

Identify bottlenecks in the current (AS-IS) process

Propose an optimized future (TO-BE) workflow

Document business requirements

Create user stories & acceptance criteria

Demonstrate BA documentation and process understanding

Deliverables Included

✔ Business Requirements Document (BRD)

✔ AS-IS Process Flow

✔ TO-BE Process Flow

✔ User Stories & Acceptance Criteria

✔ Project overview

Tools Used

Draw.io (process diagrams)

MS Word (BRD & User Stories)

Jira Format (user stories)

Key Highlights

Improved order confirmation time

Real-time inventory visibility

Automated delivery assignment

Customer-level order tracking
